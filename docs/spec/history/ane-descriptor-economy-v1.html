ANE Descriptor Economy

The reverse-engineered resource model of Apple's Neural Engine compiler, measured on h17 (M5 Max, macOS 26.7.1). Every number is reproduced from a compiled artifact — nothing here is guessed.
Descriptor table cap
54 slots
53 states + 1 header compile; a 54th state fails unable to allocate free BAR.
Cost per state<> param
2 __data segs + 1 slot
A persistent surface + its read/update working buffer, plus one descriptor-list record.
The one-line model: __data segments = outputs + 2 × states, and the compiler's ZinBarIdManager descriptor table holds 54 descriptor-list slots — so 53 states is the hard ceiling, independent of io, dtype, stripe width, and total segment count.

The descriptor tree

One state compiles to this record tree in __text. The 0x9344 descriptor-list record is the root; the two 0x9361/0x9365 state-copy records are the working buffers.

The slot word — how the table is indexed

The descriptor table is an array of slots, each holding up to two records. The slot word is the (slot, position) coordinate:

word = (slot_index << 8) | (copy << 7)

Why 154 segments can pass while 109 fail. The cap is on the state count, not the segment count: 52 states + 50 out = 154 segments compiles, but 54 states = 109 segments fails. The table that overflows is the state-descriptor allocator, not the segment table.

The sibling budget — io ports

A separate, execution-time budget (not the frontend). Measured on the e5rt lane:

out_cap(in) = max(63, 127 − in)

Outputs are capped against a ~127-port budget shared with inputs, floored at 63. The ANECCompile frontend itself accepts 200+ io ports — the limit bites at execute_sync, not compile.
