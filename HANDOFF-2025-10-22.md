### The ANE resource model (lane/probe, me) — the current frontier, mostly mapped

**Finding 1 — io-port budget (execution-time, NOT frontend).** The `ANECCompile` frontend accepts 200+ io ports. The real cap is at `execute_sync`:
```
out_cap(in) = max(63, 127 − in)
```
Outputs capped against a ~127 budget shared with inputs, floored at 63. Count budget, not byte budget.

**Finding 2 — state<> budget (genuine frontend constraint).** Independent `state<>` params hit `ANECCompile` with `unable to allocate free BAR` (`ZinBarIdManager`):
- **53 states compile + run; 54 fail.** Boundary is the state *count*, not segments/bytes/io/consts (all ruled out).

**The descriptor economy (the deep dive).** Compiled `.macho` is a `0xBEEFFACE` HWX binary. Fully decoded:
- `__data segments = outputs + 2 × states`
- Per state: 1× `0x9344` (descriptor-list record) + 1× `0x9361` + 1× `0x9365` (state-copy records)
- `0x9344` records = **states + 1** (the +1 header); the table caps at **54** (53 states + 1 header)
- `0x9344` slot word = `(slot_index << 8) | (copy << 7)` — the table is an array of slots each holding 2 records
- `0x9365` (write) field map fully decoded: `dim0`/`dim1` (+0x0e/+0x0a), stride `min(2·dim1+8, 32)` (+0x1c), region `dim1 × 1 MiB` (+0x48, ×4 slots)
- `0x9361` (read) is a **fixed template** — byte-identical across shapes and counts (the read/write asymmetry: write carries geometry, read just reads)
- **WHY 54:** the descriptor-list table holds 54 records. Not the slot-id space (56 record capacity), not a byte-extent (vmsize grows linearly).

**M4 → M5 delta:** the same 53-state program compiled for `h16g` (M4) and `h17` (M5) is **identical** — same counts, same slot model, same 54 cap. The only delta: h17 emits **one extra `0x934a`** record per program (the first `0x9344` embeds `0x934a` twice on M5, once on M4). Fixed, state-count independent. The model is **portable M4 → M5**.

## 5. Open threads (where to continue, in priority order)

1. **The `0x9442` region family's role.** It's the `2N+1` segment family (107 records at 53 states, matching `__data segments`). What does it describe — the region/surface reservations? Its slot-id space (0x23..0x3d) is sequential like `0x9344`'s. Unprobed.
2. **The `0x9344` record's remaining constants.** The embedded children (`0x934a`, `0x1340`, `0x1341`, `0x1440`) carry constant payload `0x21` (33) across all shapes. Why 33? The tail fields (1, 3, 1, 1, 1, 4) are type/count constants. Minor, but the last undecoded constants.
